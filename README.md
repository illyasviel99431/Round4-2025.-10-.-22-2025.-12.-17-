# Round4. 수원시청 홈페이지 리모델링 메인 - 행사 및 축제
* 수원시청 홈페이지를 대상으로 메인 페이지의 정보 구조와 UI/UX를 분석하고, 
  이용 과정에서 발견한 불편한 점을 개선해 보는 팀 프로젝트를 진행했습니다.

# 제작기간
2025.10.22 ~ 2025.12.17

# 프로젝트 소개
수원시청 홈페이지의 메인 페이지의 정보 구조와 UI/UX를 분석하고, 이용하면서 불편했던 점을 개선하는 팀 프로젝트입니다.

[2025 수원시 홈페이지, 행정포털 통합유지관리] 제안요청서(RFP)를 바탕으로 요구사항을 분석하고, IA(정보 구조)와 프로젝트 기획서를 작성하
며 공공 웹서비스의 기획&제작 과정을 학습했습니다.

이 중 행사 및 축제 영역을 맡아 이미지와 안내 문구를 슬라이드로 보여주는 화면을 제작헀습니다. Bootstrap을 활용해 3개의 슬라이드와 이전, 다음 버튼, 하단 슬라이드 선택 표시를 구성했습니다.

# 역할
## 행사 및 축제 화면 구현 - 나

메인 페이지의 행사 및 축제 영역에 대한 HTML 구조와 CSS 스타일을 작성했습니다.

- 슬라이드 이미지 3개와 각 이미지의 제목·설명 문구 배치
- Bootstrap 캐러셀을 활용한 이전·다음 이동 버튼과 슬라이드 선택 표시 구성
- 슬라이드 테두리, 둥근 모서리, 그림자, 이미지 채우기와 설명 문구 스타일 조정

# 협업 방식

- GitHub: 팀원별 저장소를 통해 작업 코드를 공유하고 변경 사항 관리
- IA문서: 기존 홈페이지의 PC, 모바일 메뉴 구조를 정리하고, 메인 페이지의 영역별 담당 범위 공유
- PBL 프로젝트기획서: 기존 UI문제점과 사용자 관점의 개선 의견, 구현 계획 정리
- RFP 분석워크북: 사업 목적과 요구사항을 분석하고 학습, 구현 범위 정리
- Gamma: 기존 홈페이지의 사용자 경험 분석과 시민 중심의 개선 방향 정리, 공유

# 사용 기술 및 도구
- HTML: 행사 및 축제 영역, 이미지, 설명 문구, 버튼 구성
- CSS: 슬라이드 레이아웃, 배지, 테두리, 색상, 화살표 스타일 작성
- JavaScript: iframe 콘텐츠 높이 조정 및 UI 스크립트 연결
- BootStrap: 캐러셀과 슬라이드 이동, 선택 컨트롤 구성
- jQuery: 공통 UI 스크립트·스타일  페이지의 공통 UI 구성에 활용 
- GitHub: 코드 공유 및 변경 사항 관리 
- DOCX, XLSX 문서: 요구사항 분석, IA 및 프로젝트 기획 자료 정리, 공유
- Gamma: 기존 홈페이지의 사용자 경험 분석과 시민 중심의 개선 방향 정리, 공유
